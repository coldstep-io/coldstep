A composite GitHub Action and small Linux eBPF agent for GitHub-hosted Ubuntu runners. Record process and network signals in detect mode, or enforce an egress allowlist in defend mode when you're ready to harden the boundary.

Get started View on GitHub

Built for merge gates you can reason about

Linux-only, validated on ubuntu-latest. Telemetry goes to workspace files and the Actions UI — where you already look.

Kernel-adjacent truth

Syscall-class visibility for TCP connects, DNS, TLS ClientHello SNI, filesystem signals, and process relationships.

Progressive hardening

Start in detect mode to baseline normal egress. Switch to defend mode with an explicit allowlist so unexpected destinations fail the job instead of silently leaking.

CI-native outputs

JSONL event stream, shutdown telemetry JSON, and a Markdown digest that merges into the job Summary — so reviewers see the full picture in the PR thread.

Minimal workflow 
name: coldstep

on:
  push:
  pull_request:

env:
  FORCE_JAVASCRIPT_ACTIONS_TO_NODE24: true

jobs:
  guard:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v6
      - uses: coldstep-io/coldstep@v0.2.4

Two modes, one agent

Pin a release tag (e.g. coldstep-io/coldstep@v0.2.4) rather than tracking @main.

Detect

Observe and record. No egress blocking. Ideal for baselining and building incident-friendly timelines.

Default

Defend

Block IPv4 egress outside your allowlist via cgroup connect4 / sendmsg4 and BPF LSM where available. Requires a non-empty allowlist. IPv6 is out of scope.

Opt-in

Artifacts you can diff

All paths default under $GITHUB_WORKSPACE and are overrideable via environment variables such as COLDSTEP_EVENTS_LOG.

  • .coldstep-events.jsonl Append-only event stream — source of truth for investigations.
  • .coldstep-detect.md Shutdown digest with KPI tables and collapsible sections for quick scans.
  • .coldstep-telemetry.json BPF health totals at shutdown for operational dashboards.

Optional threat enrichment

Layer AlienVault OTX lookups on IPv4 and hostname indicators in detect reports. Set OTX_API_KEY as a repository secret — enrichment is skipped entirely when unset, so fork PRs and repos without the key behave identically.

  • OTX_API_KEY Store as a repository or organization secret. Free account at otx.alienvault.com.
  • If unset No OTX calls, no API usage. Detect jobs still finish successfully.
  • Best-effort Rate limits and errors surface as warnings in the report — enrichment never fails the job. See the detect report docs for schema details.
